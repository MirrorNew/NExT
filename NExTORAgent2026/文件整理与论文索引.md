## 5. NED-Tree 代码更新说明

`NEDTree-4R.py` 当前保持论文 Algorithm 1 的主流程：输入表达式、参数集 `P` 和变量集 `V`，输出线性主干 `L_f`、新定义集 `D_new` 和辅助变量。

本次代码层面的实际更新：

1. `process` 开头调用 `_reset_state()`，避免同一个实例处理多个表达式时串入旧的 `D_new`、`queue` 或 `y_temp_k`。
2. 新增 `_replace_frac()` 和 `_replace_sqrt()`，支持常见 LaTeX 表达式输入。
3. 新增 `implicit_multiplication_application`，支持 `2x_1` 等隐式乘法。
4. 支持 `^` 到 `**` 的转换，保留论文表达式中更自然的幂写法。
5. 对负幂记录 `base != 0` 的定义域约束。
6. `process` 返回结构化字典，便于测试和后续代码映射。

轻量测试覆盖：

| 测试 | 覆盖点 |
|---|---|
| `test_case_study_expression` | 论文 case study 中 `3^x_1`, `exp`, `cos(log(x_3))` 的分解。 |
| `test_state_is_reset_between_calls` | 同一实例多次调用不污染状态。 |
| `test_latex_fraction_and_sqrt` | `\frac`、嵌套 `\sqrt{\frac{...}{...}}` 和关系符。 |
| `test_negative_power_records_domain_constraint` | 负幂定义域约束记录。 |
